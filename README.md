# BLOCK BREAKER (블록깨기)

설치나 빌드 없이 브라우저에서 바로 실행되는 블록깨기 게임입니다.
HTML, CSS, JavaScript(Canvas 2D)만으로 만들었고 코드는 `index.html` 한 파일에 들어 있습니다.

## 실행 방법

1. 이 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/GitJongH/break-out.git
   ```
2. `index.html`을 브라우저에서 엽니다. (더블클릭하면 됩니다)

## 조작법

| 입력 | 동작 |
|---|---|
| 마우스 이동 / `←` `→` (또는 `A` `D`) | 패들 이동 |
| 클릭 / `Space` | 공 발사, 레이저 발사 |
| `P` | 일시정지 / 계속 |
| `R` | 다시 시작 (일시정지·게임오버 화면) |
| `M` | 소리 켜기 / 끄기 |

터치 기기에서는 화면을 드래그해서 패들을 움직이고, 탭해서 발사합니다.

## 게임 규칙

- 공으로 블록을 모두 부수면 다음 레벨로 넘어갑니다.
- 공이 바닥으로 떨어지면 목숨이 하나 줄고, 목숨이 0이 되면 게임 오버입니다. (시작 목숨 3개, 최대 5개)
- 공이 패들의 가장자리에 맞을수록 더 비스듬하게 튕깁니다.
- 레벨이 오를수록 공이 빨라집니다.
- 패들에 닿기 전까지 블록을 연속으로 깨면 콤보가 쌓이고, 5콤보마다 점수 배율이 올라갑니다. (최대 ×5)
- 레벨을 클리어하면 남은 목숨 × 100점의 보너스를 받습니다.
- 최고 기록은 브라우저(`localStorage`)에 저장됩니다.

### 블록

- 일반 블록: 위쪽 줄일수록 점수가 높습니다. (10~70점)
- 내구도 블록: 숫자만큼 여러 번 맞아야 깨집니다.
- 회색 블록: 부술 수 없습니다. 이 블록만 남으면 레벨 클리어입니다.
- 5가지 배치가 순서대로 나오며, 한 바퀴를 돌 때마다 내구도가 1씩 올라갑니다.

## 아이템

블록을 깰 때 약 20% 확률로 떨어지며, 패들로 받으면 적용됩니다. 상단 바에 남은 시간이 표시됩니다.

| 아이템 | 효과 | 지속 |
|---|---|---|
| 패들 확장 | 패들이 1.5배 넓어집니다 | 10초 |
| 멀티볼 | 공이 3배로 늘어납니다 (최대 12개) | - |
| 슬로우 | 공이 느려집니다 | 8초 |
| 공 붙잡기 | 공이 패들에 붙고 원하는 때 발사합니다 | 12초 |
| 레이저 | 패들에서 레이저를 발사해 블록을 부숩니다 | 10초 |
| 파이어볼 | 공이 일반 블록을 튕기지 않고 뚫고 지나갑니다 | 8초 |
| 바닥 방어막 | 바닥에 막이 생겨 공을 한 번 튕겨 줍니다 | 1회 |
| 목숨 +1 | 목숨이 하나 늘어납니다 | - |
| 패들 축소 (불리) | 패들이 작아집니다 | 10초 |
| 공 가속 (불리) | 공이 빨라집니다 | 8초 |

불리한 아이템은 검붉은 캡슐에 빨간 테두리로 표시됩니다. 패들 확장과 축소, 슬로우와 공 가속은 서로의 효과를 지웁니다.

## 코드 구성

모든 코드는 `index.html` 안에 있습니다.

- `LAYOUTS`: 레벨별 블록 배치 (`.` 빈칸, `1`~`3` 내구도, `#` 부술 수 없는 블록)
- `ITEMS`: 아이템 색, 드롭 가중치(`weight`), 지속 시간(`time`), 불리 여부(`bad`)
- `update(dt)` / `draw()`: 게임 로직과 렌더링 (`requestAnimationFrame` 루프, 프레임레이트와 무관한 속도)
- 공이 빠르게 움직여도 블록을 통과하지 않도록 한 프레임을 작은 스텝으로 나눠 충돌을 검사합니다.
- 효과음은 Web Audio API로 직접 만들어 내므로 별도 음원 파일이 없습니다.

아이템 드롭 확률은 `dropItem`의 `0.2`로, 아이템 간 비율은 `ITEMS`의 `weight`로 조절합니다.
